# كشافة الفنار

## هيكل المستودع (لازم يبقى بالظبط كده)
```
index.html          ← الواجهة
sw.js               ← الـ Service Worker (اسمه sw.js بالظبط)
config.js           ← رابط Supabase ومفتاح anon
manifest.webmanifest
logo.webp
.nojekyll           ← مهم عشان GitHub Pages يخدم الملفات زي ما هي
.gitignore
.env.example
icons/              ← icon-192.png · icon-512.png · icon-maskable-512.png
supabase/           ← schema.sql · owner_only_and_private.sql (للمرجع فقط)
```

## رفع النسخة الجديدة على GitHub
1. فك ضغط الـ ZIP.
2. في المستودع: **Add file ← Upload files**، وادخل جوه المجلد اللي فكّيته، **حدد كل اللي فيه** (بما فيهم مجلدي `icons` و`supabase`) واسحبهم.
3. **أسماء الملفات لازم تبقى مظبوطة:** `index.html` و`sw.js`. لو الملف اتسمّى `index (11).html` أو `sw (1).js`، GitHub بيحفظه باسم جديد وبيسيب القديم، ومن هنا بتظهر لك النسخة القديمة.
4. اضغط **Commit changes**، وبعدين افتح تبويب **Actions** وانتظر لحد ما يظهر ✔ أخضر على "pages build and deployment" (دقيقة تقريبًا).
5. **Settings ← Pages:** تأكد إن الـ Source هو `Deploy from a branch`، والفرع `main`، والمجلد `/ (root)`.

## لو لسه ظاهر الموقع القديم
- افتح الموقع واعمل تحديث إجباري: `Ctrl+Shift+R` على الكمبيوتر.
- على الموبايل: امسح بيانات الموقع من إعدادات المتصفح، ولو كنت مثبّته كتطبيق، احذفه وثبّته تاني.
- GitHub Pages بيخزّن الملفات نحو 10 دقايق، فاستنى شوية بعد الرفع.

## تحديث نسخة جديدة لاحقًا
غيّر رقم النسخة في **مكانين** معًا:
- في `sw.js`: `const V='fanar-v7'` ← `fanar-v8`
- في `index.html`: `register('sw.js?v=7')` ← `sw.js?v=8`

## قاعدة البيانات (Supabase)
قاعدة البيانات **متحدّثة بالفعل** (الطلائع والنقاط والتحديات والشارات ولوحة الشرف والمكتبة وسياسات الصلاحيات). ملفات `supabase/` بقت **للمرجع فقط**.
- **ما تشغّلش `schema.sql` تاني:** هيرجّع سياسة الإعلانات (`ann_sel`) لتكون مفتوحة لأي حد، وده بيضعف الحماية الحالية.
- لازم يبقى في Storage الـ buckets: `media` (صور) و`library` (مكتبة الفنار، خاص).
- قبل أي تعديل في القاعدة، خد نسخة احتياطية من جدول `records`.

## الأمان (مهم)
- GitHub Pages موقع ثابت: أي مفتاح في `config.js` بيوصل للمتصفح. مفتاح **anon** مصمَّم يبقى عام، والحماية الحقيقية من سياسات RLS في Supabase.
- **ممنوع** تحط مفتاح `service_role` في أي ملف أو ترفعه على GitHub.
- `.gitignore` بيمنع رفع أي ملف `.env` بالغلط. و`.env.example` للتوثيق فقط، لأن الموقع بيقرأ الإعدادات من `config.js`.
